# Athenium Institute — Academia LMS Home

A mobile-first learning-platform homepage for a demo academy. Search and filter a
six-course catalog, open a tracked curriculum with a persistent progress ring, meet
the instructor, compare pricing, reserve a seat with a validated enrollment form, and
preview a personalized certificate — all on one page, no login required.

- Single-file `index.html` (two inline scripts, CSS injected, Google Fonts via link)
- Content customizable through `data-fws-slot` attributes (see `slots.md`)
